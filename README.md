# 反則上等！ (Hansoku Joto!)

**ルール改変 × 超連鎖ローグライク 3D カードバトル**（Three.js + Vite + Web Audio API）

> 「考えている間は緻密な戦略ゲーム、『発射！』を押した瞬間はド派手な超連鎖バカゲー！」

## 🎮 ブラウザで今すぐ遊ぶ (Play Online)

👉 **[https://kogetyadot.github.io/hansoku-joto/](https://kogetyadot.github.io/hansoku-joto/)**

## ✨ 主な特徴

- **3ステップ合体コンボ**：行動カード（黄）× 改変カード（青・最大2〜3枚）を組み合わせて『🔥発射！』で連鎖発動
- **赤ペン永続ルール書き換え**：カードの効果テキストを赤ペンで取り消して永続的に魔改造（「3連発→5連発」「敵1体→敵全員」「命中時誘爆付与」など）
- **10種の反則ルール**：死体爆弾ルール、爆風バリア、連撃インフレ、余剰ダメージ転嫁、要塞砲撃ルールなど戦場全体のルールを改変
- **スタイライズド3Dアリーナ＆物理演出**：Three.js による地下反則リング、ヒットストップ、カメラシェイク、プロップ飛散、ラグドール吹き飛びKO
- **プロシージャル音響**：Web Audio API による動的BGMシーケンサー＆連鎖数連動ピッチ上昇効果音（BGM/SE個別ON/OFF対応）

## 🛠️ ローカル開発

```bash
npm install
npm run dev
```
